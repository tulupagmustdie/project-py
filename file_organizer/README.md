# File Organizer

Консольная программа для просмотра файлов в папке. Выводит название,
расширение, размер в байтах и локальную дату последнего изменения.
Содержимое файлов не изменяется.

Требуется Python 3.11 или новее. Дополнительные зависимости не нужны.

## Запуск

Из папки `file_organizer`:

```sh
python3 main.py
```

После запуска укажите путь к папке, например `~/Downloads`.
Путь с пробелами вводится без кавычек. Относительные пути отсчитываются
от текущей рабочей папки.

## Правила сканирования

- Обрабатываются только файлы непосредственно в указанной папке.
- Скрытые файлы, вложенные папки и символические ссылки пропускаются.
- Расширения приводятся к нижнему регистру. Для составных расширений
  используется последний суффикс: `archive.tar.gz` → `.gz`.
- Файлы без расширения отмечаются как `без расширения`.
- Файлы нулевого размера включаются в результат.

При ошибке чтения метаданных файла выводится предупреждение, сканирование
продолжается. Если прочитать саму папку невозможно, программа завершается
с сообщением об ошибке.

## Структура

- `main.py` — ввод пути и запуск программы.
- `scanner.py` — проверка пути и сбор метаданных.
- `report.py` — вывод списка файлов.
- `storage.py` — модуль для сохранения отчётов (пока не реализован).
- `data/` — каталог для отчётов.
- `test_files/` — каталог для тестовых файлов.

Содержимое `data/` и `test_files/` исключено из Git, кроме `.gitkeep`.
